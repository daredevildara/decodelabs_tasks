# Data Analytics Internship Portfolio
A practical portfolio of data analytics projects completed during my internship at Decode Labs. 

## Overview

This repository contains my data analytics projects completed during my internship at Decode Labs.
The projects demonstrate my practical application of data analytics across data preparation, validation, exploratory analysis, business interpretation, and insight communication.
Each project is organised independently, with its supporting analysis files, documentation, and visual evidence included within its respective folder.
