# Data Analytics Internship Portfolio

A practical portfolio of data analytics projects completed during my internship at Decode Labs.

## Overview

This repository contains my data analytics projects completed throughout my internship at Decode Labs. The projects demonstrate my practical application of data analytics across data preparation, validation, exploratory analysis, SQL-based analysis, business interpretation, data visualization, and insight communication.

The projects build progressively on the same sales dataset, allowing me to apply different analytical approaches at each stage while developing a more complete understanding of the data.

Each project is organised independently, with its supporting analysis files, documentation, screenshots, and visual evidence included within its respective folder.

## Projects

Key areas covered:

- Data validation
- Missing and inconsistent values

- Sales trend analysis

### Project 4 — Data Visualization & Sales Performance Dashboard

The final project of the internship project sequence, focused on transforming analytical findings into a clear and interactive dashboard.

The project was designed around the business question:

> What factors are driving order value, and where are the strongest opportunities to improve business performance?

The dashboard addresses four analytical questions:

1. How is order performance changing over time?
2. Which products contribute most to order value?
3. Which acquisition sources generate the greatest order activity and value?
4. How does basket size influence order value?

The final dashboard includes:

- Total Order Value
- Unique Customers
- Average Order Value
- Total Orders
- Order Value by Product
- Order Value by Acquisition Source
- AOV by Basket Size
- Monthly Order Value Trend
- Year filtering
- Product filtering

Key areas covered:

- Data visualization
- Dashboard design
- PivotCharts
- KPI development
- Slicers and interactive filtering
- Trend analysis
- Comparative analysis
- Data storytelling
- Business-focused insight communication
- Excel dashboard development

## Portfolio Approach

My approach throughout these projects is centred on moving beyond simply producing calculations or charts.

The project sequence follows a progressive analytical process:

Clean → Validate → Explore → Query → Visualize → Interpret → Communicate

Each stage builds on the previous one, from preparing reliable data and identifying patterns to using SQL for structured analysis and ultimately presenting findings through an interactive dashboard.

The supporting documentation within each project explains the analytical process, the evidence behind the findings, and the practical implications of the results.

## About This Repository

This repository serves as a record of my practical data analytics work and progression throughout my Decode Labs internship.

Across the four projects, I applied different analytical techniques to the same underlying dataset, progressing from data preparation and exploratory analysis to SQL analysis and dashboard development.

The completed project sequence represents the culmination of this internship phase and provides a practical demonstration of my developing skills in data preparation, analysis, SQL, visualization, and business insight communication.
